Tema 1 · Fundamentos

💡 ¿Qué es un flujograma?

Representación gráfica secuencial de un proceso, algoritmo o sistema, con símbolos estandarizados (rectángulos, rombos, flechas) que muestran el inicio, el fin y los pasos intermedios.
👁 Visualización claraSustituye textos largos por un mapa visual.
📈 Mejora de procesosDetecta actividades innecesarias y cuellos de botella.
📏 EstandarizaciónTodos ejecutan el procedimiento igual.
🧭 Toma de decisionesMapea rutas de acción según decisiones.
🎓 CapacitaciónFacilita el aprendizaje del nuevo personal.

Tema 2 · Mapa Global

🗺 Diagrama o Mapa Global de Procesos

  • Ilustra cómo funciona un proceso y ayuda a identificar ineficiencias.
  • ¿Cuándo se diseña un proceso? Bien/servicio nuevo · modificación de producto · nueva tecnología.
  • Se identifican: participantes, inputs/outputs, pasos y áreas intermedias.

Ejemplo: Proceso de Compras (carriles por área)

Depto. Solicitante

① Solicitud de materiales

Almacén

② Revisa existencias
⑥ Surte materiales
⑦ Inspección de materiales

Depto. de Compras

③ Elabora requisición
④ Elabora orden de compra

Proveedor

⑤ Selecciona proveedor
⑧ Surte orden de compra

🪜 Pasos para hacer un Diagrama Global

  1. Determinar inicio (input) y fin (output).
  2. Identificar actividades que generan el output.
  3. Identificar participantes/responsables.
  4. Identificar la secuencia de pasos.
  5. Precisar inputs/proveedores y outputs/destinatarios de cada paso.
Tema 2 · Diseño

✏️ Pasos para construir un Flujograma

  1. Determinar el primer y último paso.
  2. Anotar el primer paso arriba con una elipse.
  3. Escribir la secuencia: rectángulos (actividades) y rombos (decisiones).
  4. Señalar el sentido con flechas de inicio a fin.
  5. Regresar al inicio y repetir el rombo para toda ramificación.
  6. Anotar el último paso abajo con elipse y conectar ramificaciones.

⚖️ Diferencias clave

Mapa Global de ProcesosFlujograma
Enfoca inputs/outputs e interrelación entre organizaciones.Enfoca el flujo secuencial de trabajo dentro de uno o varios pasos.
No detalla el flujo dentro de un paso.Muestra flujos físicos y de información.
No usa símbolos estándar.Usa simbología estándar (ASME, ANSI, ISO…).

📱 Caso: cambio de carcasas de móvil

El cliente tiene una semana para pedir el cambio. Puntos críticos: no se validó el modelo en inventario y el color puede no estar disponible → se agregan rombos adicionales con rutas de solución antes de presentar el diagrama final a socios, directivos y colaboradores.
